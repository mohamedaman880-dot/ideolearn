# IdeoLearn Platform

Bilingual (English/Arabic) educational consultancy and university/program directory with a single-administrator CMS.

## Project Structure
- `frontend/` — React + Vite + TypeScript SPA
- `backend/` — Node.js + Express + TypeScript + Prisma REST API
- `docs/` — Software Requirements Specification (SRS), System Architecture Document (SAD), and Database Design Document (DDD)
